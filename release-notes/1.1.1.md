## CoordsOnScreen 1.1.1

A polish release that makes the new biome and structure lines play nicely with **modded content** — no behavior changes for vanilla play.

### Modded biomes
- Biome names now show a **clean, prettified fallback** when a modded biome ships without its own translation (e.g. instead of `biome.mymod.crystal_forest` you'll see "Crystal Forest"). Mod-provided translations are honored when present.
- Modded biomes outside the curated palette now pick the **water color** instead of the grass color when the biome name suggests water (`ocean`, `river`, `beach`, `shore`, `sea`). Modded oceans and beaches no longer come out as generic green.

### Modded structures
- Modded structures can supply their own name via a `structure.<namespace>.<path>` translation key, and it'll be used; structures without one keep the prettified-id fallback ("crystal_tower" → "Crystal Tower").
- Nested resource paths (`/`) are now treated as word boundaries when prettifying, alongside the existing snake_case handling.

### Notes
- No new settings — these improvements apply automatically.
- Singleplayer is still the only place the structure line can appear (server-side limitation; nothing the client can do about it).

---
*Requires Fabric API and Cloth Config. ModMenu is optional (used to open the settings screen).*
